# 🎓 Telegram-бот для очередей по предметам (для групп и бесед)

Удобный бот для организации очередей на пары, лабы, экзамены и сдачи предметов в студенческих группах Telegram.

---

## ✨ Возможности
- **Работа в группах и личных сообщениях**: бот оптимизирован для работы в беседах групп (у каждой группы свои независимые предметы и очереди).
- **Интерактивные кнопки (Inline)**:
  - ➕ **Запись в 1 клик** (автоматически берется имя и ник из Telegram).
  - ✍️ **Запись под своим именем** (если в Telegram никнейм отличается от ФИО в ведомости).
  - ❌ **Выписаться из очереди** в любой момент.
  - 🔄 **Обновление списка** в реальном времени.
  - 🧹 **Очистка очереди** (перед началом новой недели/пары).
- **Гибкое расписание открытия и закрытия записи**:
  - 🗓 **Еженедельно** (например: *каждый вторник с 09:00 до 18:00*). Если студент нажимает кнопку раньше — бот вежливо сообщает точное время открытия; если позже — сообщает, что запись закрыта.
  - 📅 **Конкретная дата** (например: *25.10.2026 с 10:00 до 12:00*).
  - 🟢 **Всегда открыта** (без временных ограничений).
- **Управление предметами**:
  - Любой участник может добавить предмет через интерактивный пошаговый мастер (`/add_subject` или кнопка в меню).
  - Любой участник может удалить предмет (`/del_subject` или кнопка в меню).
  - Возможность установить лимит мест (или без лимита).

## 🚀 Быстрый старт и запуск

### 1. Получение токена бота
1. Перейдите в Telegram к официальному боту [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название бота (например: `Очередь ОмГУ`) и юзернейм (должен оканчиваться на `bot`, например `omsu_queue_bot`).
4. Скопируйте выданный токен (вида `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`).
5. *(Рекомендуется для групп)*: В [@BotFather](https://t.me/BotFather) отправьте `/setprivacy` -> выберите вашего бота -> выберите **Disable** (это позволит боту без задержек обрабатывать сообщения в беседах). Также в `/setjoingroups` убедитесь, что включено **Enable**.

### 2. Настройка файла `.env`
Откройте файл `.env` в папке бота и вставьте ваш токен:
```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
TIMEZONE=Asia/Omsk
DB_PATH=queue_bot.db
```
*(Если вы находитесь в другом часовом поясе, например в Москве, укажите `TIMEZONE=Europe/Moscow`)*.

### 3. Запуск бота
- **Простой способ (Windows)**: дважды кликните по файлу `start.bat`.
- **Через консоль**:
  ```powershell
  .\venv\Scripts\activate
  python main.py
  ```

## 👥 Как использовать бота в группе
1. Добавьте созданного бота в вашу учебную группу в Telegram.
2. Дайте боту права администратора (или обычные права на чтение и отправку сообщений).
3. Напишите команду:
   ```
   /queue
   ```
   (или `/start`, `/help`)
4. Появится интерактивное меню:
   - Нажмите **➕ Добавить предмет** и следуйте простым подсказкам бота (введите название, выберите день недели и время).
   - Выберите созданный предмет — появится карточка очереди со списком записавшихся и кнопками записи.
   - Каждый студент нажимает кнопку записи, и бот мгновенно обновляет актуальный список прямо в сообщении!
